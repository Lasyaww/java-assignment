# Java Assignment 4 - CO4

Source: Assignment CO4 - Event-Driven GUI Design.

## Task files
- Task 1: `task-01/FeeWindow.java` - UI/service separation and parameterized JDBC.
- Task 2: `task-02/AppointmentDesk.java` - AWT appointment form and dependent doctor list.
- Task 3: `task-03/LibrarySearchScreen.java` - resizable AWT layout.
- Task 4: `task-04/DrawPad.java` - mouse events, stored points and repaint.
- Task 5: `task-05/Converter.java` - four event-handling styles and Enter-key conversion.
- Task 6: `task-06/EventRegistrationApp.java` and `schema.sql` - layered Swing/JDBC registration.

## Run
Open a task folder and run `javac FileName.java` then `java ClassName`. GUI tasks require a desktop environment. Tasks 1 and 6 require MySQL Connector/J and a configured local MySQL database. Set `JAVA_DB_URL`, `JAVA_DB_USER` and `JAVA_DB_PASSWORD`. Run Task 6's schema.sql first.

Source code and SQL schema only; no screenshots or output files.
